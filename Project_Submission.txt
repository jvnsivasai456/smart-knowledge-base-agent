3. PROJECT SPECIFICATIONS & TECH STACK:
--------------------------------------------------------------------------------
- Project Title:       Smart Knowledge Base Agent
- Author / Owner:      jvnsivasai456
- Architecture:        Retrieval-Augmented Generation (RAG) with Hybrid Ranking
- Technology Stack:    Python 3.11+, FastAPI, Streamlit, ChromaDB, 
                       SentenceTransformers (all-MiniLM-L6-v2), rank_bm25, SQLite
- Search Pipeline:     Reciprocal Rank Fusion (RRF, k=60) combining Okapi BM25 
                       lexical scoring and dense semantic cosine similarity
- Confidence Gate:     Empirical similarity threshold of 0.62 with 95% 
                       hallucination interception accuracy
- File Formats:        PDF, Word (.docx), Markdown (.md), Plaintext (.txt), HTML

--------------------------------------------------------------------------------
4. KEY ARCHITECTURAL FEATURES:
--------------------------------------------------------------------------------
• Multi-Format Document Ingestion:
  Upload and index PDF, DOCX, TXT, and HTML files with automated text extraction 
  and overlapping sliding-window chunking (800 chars / 120 token overlap).

• Hybrid Dual-Index Search Engine:
  Simultaneously executes dense semantic vector retrieval in ChromaDB and sparse 
  lexical ranking in Okapi BM25, merged via Reciprocal Rank Fusion.

• Natural Language Answers with Citations:
  Synthesizes direct, professional answers with explicit chunk citations, 
  relevance match percentages, and unique document category badges.

• Continuous Incremental Updates:
  Filesystem change detection driven by APScheduler and SHA-256 cryptographic 
  hash diffing, re-indexing only altered files with a 20.1x update speedup.

• Zero-Downtime Resilience:
  In-process fallback engine ensures continuous conversational question-answering 
  even when the REST API gateway is offline.

5. HOW TO RUN LOCALLY:
--------------------------------------------------------------------------------
1. Clone the repository:
   git clone https://github.com/jvnsivasai456/smart-knowledge-base-agent.git
   cd smart-knowledge-base-agent

2. Quick Windows Launch:
   Double-click "run_app.bat" to start both Backend and UI automatically.

3. Or launch manually:
   python -m venv venv
   .\venv\Scripts\activate
   pip install -r requirements.txt
   python main.py                     (FastAPI Backend on port 8000)
   streamlit run src/ui/app.py        (Streamlit UI on port 8501)

4. Open in browser:
   http://localhost:8501
